## 나의 첫 번째 블로그 게시글

안녕하세요! 국립부경대학교 컴퓨터·인공지능공학부에 재학 중인 김민준입니다.

이번 오픈소스 프로그래밍 수업을 통해 GitHub Pages와 Jekyll을 활용하여 개인 웹사이트를 제작했습니다.

### 웹사이트 제작 과정

1. Ruby 및 Jekyll 설치
2. GitHub 저장소 생성
3. al-folio 테마 적용
4. GitHub Actions를 이용한 자동 배포
5. 개인 프로필 및 홈페이지 수정

### 느낀 점

처음에는 GitHub Pages와 Jekyll의 사용법이 익숙하지 않아 어려움이 있었지만, 직접 오류를 해결하고 웹사이트를 배포하면서 GitHub와 오픈소스 도구의 활용 방법을 배울 수 있었습니다.

앞으로 이 블로그에 프로그래밍 학습 내용과 프로젝트 경험을 기록할 계획입니다.
